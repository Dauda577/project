## 2026-07-27 10:33 UTC
Incident: cloudflared "restarts on crash" claim was false. VBS used Run(cmd, 0, False) which returns immediately, so Task Scheduler saw the launch as instantly "successful" and never tracked the real cloudflared.exe process — RestartOnFailure never triggered on actual crashes.
